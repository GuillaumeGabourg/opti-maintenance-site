# Opti'Maintenance Industrie

Site vitrine d'Opti'Maintenance Industrie, Malo Maheas, technicien de maintenance industrielle indépendant en Mayenne : mécanique, électrique, variation de vitesse et automatisme.

Site statique (HTML, CSS, JavaScript), sans dépendance ni étape de build. Ouvrir `index.html` ou servir le dossier avec n'importe quel serveur statique.

- `index.html` : la page
- `css/`, `js/`, `fonts/` : styles, scripts, polices auto-hébergées
- `assets/` : logo (provisoire) et photos de terrain
- `mentions-legales.html` : à compléter (SIRET, forme juridique, adresse)
- `DESIGN.md`, `PRODUCT.md` : système visuel et contexte produit

Le formulaire de contact est prévu pour Netlify Forms ; sur GitHub Pages, l'envoi renvoie vers le téléphone et l'e-mail.
